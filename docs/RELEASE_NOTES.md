# GitHub WebView (Locked) 1.0.0

Site-configuration adaptation of Arena WebView (Locked) 1.2.0. Separate app ID and icon;
GitHub start page and role-based resource policy; preserved proxy, UI, input/rendering and navigation
implementation. Honest WebView user agent, with provider restrictions respected.

No new app UI or download/file-picker capability. See the current test report before installation.
The release is signed with the original public demo key unless private signing secrets are supplied.
